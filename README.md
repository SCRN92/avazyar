# آوازیار (نسخه‌ی ۰.۴)

وب‌اپ نصب‌شدنی (PWA) برای آموزش آواز ایرانی از صفر.

**نسخه‌ی آنلاین:** https://avazyar.noonbarbari.xyz

برنامه‌ی کارهای بعدی در [ROADMAP.md](ROADMAP.md) هست.

## امکانات
- تشخیص لحظه‌ای زیر و بمی صدا از میکروفون (الگوریتم YIN)، به‌همراه ربع‌پرده‌ها (کرن و سری)
- ۹ درس: گرم کردن، تست محدوده‌ی صدا و تیپ صدای تخمینی، نت خانه، نفس و نگه داشتن نت، هم‌صدا شدن با نت، «دو، ر، می»، اولین ربع‌پرده (شور)، و دو درس گوش که میکروفون نمی‌خوان
- «تمرین امروز»: یه جلسه‌ی ۵، ۱۰ یا ۱۵ دقیقه‌ای که خود برنامه می‌چینه (گرم کردن، یه درس تازه، و مرور درس‌هایی که امتیاز کمتری دارن)
- درس‌ها سطح دارن: با بهتر شدن امتیاز، دقت لازم بیشتر می‌شه
- تمرین آزاد (تیونر) با نمودار زنده‌ی صدا و نت پایه‌ی ثابت برای تمرین فاصله‌ها
- امتیاز هر تمرین، شمارش روزهای پشت‌سرهم، و صفحه‌ی پیشرفت: خلاصه‌ی هفته، روند هر درس، تغییر محدوده‌ی صدا، و دقت روی هر نت
- کار آفلاین، و ذخیره‌ی همه‌ی داده‌ها فقط روی خود دستگاه

### تازه‌های نسخه‌ی ۰.۴
- صفحه‌ی پیشرفت تازه: روزهای تمرین هفته، روند امتیاز هر درس، نمودار محدوده‌ی صدا در طول زمان، و اینکه هر نت رو معمولاً بالا می‌خونی یا پایین
- اگه برنامه به نسخه‌ی قدیمی‌تر برگرده، پیشرفت ذخیره‌شده دست‌نخورده می‌مونه

### تازه‌های نسخه‌ی ۰.۳
- «تمرین امروز» (از ۰.۳.۱)
- درس «نفس و نگه داشتن نت»: مدت و یکنواختی نگه داشتن یه نت رو اندازه می‌گیره
- دو درس گوش بدون میکروفون: «بالاتر یا پایین‌تر؟» و «می یا می کرن؟»
- سطح‌بندی درس‌ها و تکرار خودکار نت‌هایی که سخت بودن
- نت پایه‌ی ثابت در تمرین آزاد
- درس‌ها حالا به‌صورت داده در `js/lessons.js` تعریف می‌شن

### تازه‌های نسخه‌ی ۰.۲
- تست میکروفون: حساسیت رو با سر و صدای محیط تنظیم می‌کنه
- صفحه حین تمرین خاموش نمی‌شه
- گرفتن و بازگردانی فایل پشتیبان از پیشرفت
- راهنمای نصب روی آیفون
- فونت از خود برنامه لود می‌شه (بدون وابستگی به سرور دیگه)، و وقتی نسخه‌ی جدید بیاد برنامه خبر می‌ده
- دسترس‌پذیری بهتر: اعلام بازخورد برای صفحه‌خوان‌ها، کنتراست رنگ‌ها، و حرکت کمتر برای کسایی که این رو می‌خوان

## اجرا روی کامپیوتر
داخل پوشه‌ی پروژه:
```bash
python3 -m http.server 5173
```
بعد در Chrome آدرس `http://localhost:5173` رو باز کنید.

## آزمون‌ها
به Node.js نسخه‌ی ۲۰ یا بالاتر نیاز داره. هیچ بسته‌ای نصب نمی‌شه.
```bash
npm test
```

## اجرا با Docker
```bash
docker compose up -d --build
```
برنامه روی `http://127.0.0.1:8793` بالا میاد (پورت رو می‌شه با `AVAZYAR_PORT` عوض کرد). کانتینر فقط فایل‌های استاتیک رو با nginx سرو می‌کنه؛ https رو باید یه reverse proxy جلوی اون بده. نمونه‌ی تنظیم nginx سرور در `deploy/` هست.

## انتشار روی سرور
```bash
./deploy/deploy.sh <نام-ssh-سرور>
```
این اسکریپت آزمون‌ها رو اجرا می‌کنه، فایل‌ها رو به سرور می‌فرسته، کانتینر رو دوباره می‌سازه و منتظر سالم بالا اومدنش می‌مونه.

قبل از هر انتشار، شماره‌ی نسخه رو در `js/version.js` عوض کنید (و اگه عدد اول یا دوم عوض شد، در عنوان همین فایل). برنامه‌های باز با همین شماره می‌فهمن نسخه‌ی جدید اومده.

## نصب روی گوشی
میکروفون فقط روی آدرس امن (https) کار می‌کنه.
- **اندروید:** بعد از باز کردن آدرس در Chrome، از منو گزینه‌ی «افزودن به صفحه‌ی اصلی» یا «نصب برنامه» رو بزنید.
- **آیفون:** در Safari دکمه‌ی «اشتراک‌گذاری» و بعد «Add to Home Screen» رو بزنید.

| `js/synth.js` | پخش نت مرجع و نت پایه |

| `js/lessons.js` | تعریف درس‌ها (داده)، سطح‌ها، سؤال‌های درس گوش، و چیدن «تمرین امروز» |
| `js/exercise.js` | منطق تمرین نگه داشتن نت |

| `docker/`، `deploy/` | ساخت کانتینر و انتشار |

## آزمایش بدون میکروفون
با اضافه کردن `?sim` به آدرس، به‌جای میکروفون یه صدای آزمایشی استفاده می‌شه. از کنسول می‌شه کنترلش کرد:
- `__sim.setFreq(220)` فرکانس رو عوض می‌کنه
- `__sim.mute(true)` صدا رو قطع می‌کنه (برای آزمایش سکوت)
- `__sim.setGain(0.05)` بلندی صدا رو عوض می‌کنه
