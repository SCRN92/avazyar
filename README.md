# آوازیار (نسخه‌ی ۰.۱)

وب‌اپ نصب‌شدنی (PWA) برای آموزش آواز ایرانی از صفر.

**نسخه‌ی آنلاین:** https://mehroruji-hue.github.io/avazyar/

## امکانات نسخه‌ی ۰.۱
- تشخیص لحظه‌ای زیر و بمی صدا از میکروفون (الگوریتم YIN)، به‌همراه ربع‌پرده‌ها (کرن و سری)
- ۶ درس: گرم کردن، تست محدوده‌ی صدا و تیپ صدای تخمینی، نت خانه، هم‌صدا شدن با نت، «دو، ر، می»، و اولین ربع‌پرده (شور)
- تمرین آزاد (تیونر) با نمودار زنده‌ی صدا
- امتیاز هر تمرین، شمارش روزهای پشت‌سرهم، و نمودار پیشرفت
- کار آفلاین، و ذخیره‌ی همه‌ی داده‌ها فقط روی خود دستگاه

## اجرا روی کامپیوتر
```bash
python -m http.server 5173 -d avaz-app
```
بعد در Chrome آدرس `http://localhost:5173` رو باز کنید.

## نصب روی گوشی
میکروفون فقط روی آدرس امن (https) کار می‌کنه. پس برای استفاده روی گوشی، محتوای این پوشه باید روی یه هاست استاتیک با https قرار بگیره. بعد از باز کردن آدرس در Chrome اندروید، از منو گزینه‌ی «افزودن به صفحه‌ی اصلی» یا «نصب برنامه» رو بزنید.

## ساختار فایل‌ها
| فایل | کار |
|---|---|
| `js/pitch.js` | ورودی میکروفون و تشخیص زیر و بمی |
| `js/notes.js` | نام نت‌ها (با ربع‌پرده)، تیپ صدا |
| `js/lane.js` | نمودار زنده‌ی صدا |
| `js/synth.js` | پخش نت مرجع |
| `js/store.js` | ذخیره‌ی پیشرفت |
| `js/app.js` | صفحه‌ها و درس‌ها |
| `sw.js` | کار آفلاین |

## آزمایش بدون میکروفون
با اضافه کردن `?sim` به آدرس، به‌جای میکروفون یه صدای آزمایشی استفاده می‌شه. فرکانسش رو می‌شه از کنسول با `__sim.setFreq(220)` تغییر داد.
